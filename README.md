# GupFit build copy

Build-only copy of a small personal iPhone app (SwiftUI) for tracking food, workouts and recipes. GitHub Actions
builds it on a hosted Mac: an unsigned IPA (artifact `GupFit-ipa`), simulator screenshots from invented demo data
(artifact `screenshots`) and, when the App Store Connect secrets are set, a TestFlight upload for internal testing.
Development happens elsewhere; not maintained for anyone else, and issues or pull requests aren't looked at.
